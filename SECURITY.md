# Sicherheit

Belegtext läuft in einer Umgebung mit vertraulichen Belegdaten. Wenn Sie eine Sicherheitslücke finden, melden Sie sie bitte **nicht** als öffentliches Issue, sondern vertraulich:

- über „Report a vulnerability“ im Reiter **Security** dieses Repositorys, oder
- per E-Mail an belegtext@rasch.finance.

Bitte keine echten Belege oder Mandantendaten mitschicken; die Musterbelege in `store/musterbelege/` reichen zum Nachstellen. Wir melden uns innerhalb weniger Tage.
